# verify_independent.py — 脫敏公開版的第二道閘

> 私有工具。它讀的名稱表、對照表，與它產出的報告**都含真名**，永不進任何公開輸出。
> 本檔與腳本原始碼本身不含真名（`--selftest --names ... --maps ...` 會檢查）。

## 為什麼有它

主腳本的置換與掃描共用同一套邊界假設，會對自己看不見的殘留自報零命中。
本驗證器**由另一人、在不閱讀主腳本與其 selftest 的前提下**，只依規格寫成，
用來抓主腳本掃描的盲點。它不 import 主腳本，也不共用任何程式碼。

## 用法

```
python _publish/verify_independent.py \
    --names <names.yaml> --maps <private_maps.yaml> --tree <輸出樹> \
    [--policy <builder 的政策檔.yaml>] [--names-exemptions [--repo <repo 代號>]] \
    [--exempt _publish/verify_exempt.yaml] [--synthetic <合成區段與佔位清單.yaml>] \
    --report <樹外路徑>/report.md [--max-per-key N]

python _publish/verify_independent.py --selftest [--names <names.yaml>] [--maps <private_maps.yaml>]
```

- `--policy`：直接讀 builder 政策檔的 `synthetic_ranges`／`placeholders`（當資料讀，不讀其程式）。
- `--names-exemptions`：直接套名稱表 `scan.exemptions`（`--repo` 限定該 repo 的條目）；報告逐條列放行數。
  不帶時不套任何表內豁免（先看豁免前的全貌，再帶旗標看豁免後）。

- 直譯器：`%LOCALAPPDATA%/Python/pythoncore-3.14-64/python.exe`，設 `PYTHONIOENCODING=utf-8`；只需 PyYAML 與標準函式庫。
- 退出碼：`0` 無命中、`4` 有命中（含形狀命中）、`1` 用法或檔案錯誤（含豁免缺欄、合成清單格式錯、報告路徑落在 `--tree` 內）、`5` 自測失敗。
  歧義、未掃、表內 regex 編譯失敗、regex 未對應值都是**警告**，不改退出碼，但會寫在報告第一行。
- 全程唯讀：對 `--tree` 只做 `open(..., "rb")`；唯一的子行程是對樹內 `.git` 跑的唯讀 git 指令（`log`、`for-each-ref`，
  帶 `GIT_OPTIONAL_LOCKS=0`）。報告必須寫在樹外。
- 效能：約 260 檔／14 MB 的樹約 1.5 分鐘（第一輪 3.5 分鐘；數字比對改成 trie 樣式）。

## 規則摘要

| 規則 | 做法 |
|---|---|
| 讀表 | 泛用走訪：任何帶 `real`（或 `real_zh`）字串欄位的條目都是真名。`categories.keep`、`alias: <keep>`、`action: keep` 不算真名。數字類真值取自對照表所有 map 的 key。 |
| 公開值集合 | 表內所有 `alias*`／`token*` 欄位值＋對照表所有假值（`<...>` 標記與空字串除外；glob 的 `*` 去掉）。 |
| 名稱 ≥5 字 | 不分大小寫子字串，內容與路徑都掃。 |
| 多字名稱 | 真名內部有空白、`_`、`.`、`-`、`+` 分隔的：字與字之間允許零到多個上述分隔（含任何 Unicode 空白與換行），不分大小寫；無分隔的連寫形也命中。首尾那個字若 ≤4 字元，該側套短名邊界（不含複數）。 |
| 名稱 ≤4 字 | 表列字形＋自動衍生的全小寫、首字大寫、全大寫三形（表標 `case: exact` 者不衍生），大小寫精確比對。邊界：前後不是英文字母即命中；小寫接大寫（駝峰）與「大寫接大寫＋小寫」也算邊界；後接 `s`／`es` 再接非字母也算（全大寫形另接受 `S`／`ES`）。字形本身首／尾不是字母時該側不需邊界。 |
| 人名 | 長人名的全大寫、全小寫由「不分大小寫」涵蓋；帳號形（`first.last`、`first_last`、`firstlast`）由多字規則涵蓋；短人名由衍生三形涵蓋。 |
| 電話形真名 | 只含數字與 `+ - ( ) .` 空白、至少 8 位數的真名：數字間允許任何上述分隔或無分隔。 |
| 路徑類 | `scope: path` 或含 `/`、`\` 的真名，產生 `/`、`\`、`\\` 三種分隔形。含 `*` 的真名轉為 glob 樣式比對。 |
| 表內 regex 條目 | 照表的樣式掃。無對照語意者：命中即算。帶 `map_group`／`value_group`／`private_map`／`prefix_alias` 者：擷取值是對照表假值 ⇒ 不算（計入遮罩）；是真值 ⇒ 命中（若數字比對已報則不重報）；兩者皆非 ⇒ `known_only` 略過、`permutation` 列「regex 未對應值」警告、其餘算命中。編譯失敗列報告「Table regex compile errors」節。 |
| 巢狀 | 同一處被多個真名命中時只報最長者。 |
| 遮罩 | 命中完整落在某公開值（不分大小寫）的出現範圍內即不算，計入報告「Masked」節。 |
| 數字 | 對照表每個真值：前後不是數字即命中（字母、底線相鄰也算）。字母前綴＋數字的真值（序號、料號、文件編號）不分大小寫，前綴與數字之間可多一個 `-` 或空白。所在連續十六進位串 **≥16** 字元 ⇒ 列「雜湊形略過」不算命中；較短者一律算命中。 |
| 形狀（第 20 條） | 對照表每一類：由真值歸納「真前綴」集合與本體形狀（每個位置的類別：數字／大寫／小寫／其他字元，連續同類合併成段），由假值歸納「公開前綴」。輸出內任何「真前綴（不分大小寫）＋零到一個 `-`、`_`、空白＋本體形狀（數字段長度可差一位）」、前後不接英數的字串，若不是任何類的假值、不是已知真值（已由數字比對報）、不在合成清單內，就算「形狀命中」。**純數字類（無字母前綴）不做形狀掃描。**真前綴同時是公開前綴者不形狀化，報告列出。 |
| 合成清單 | `--synthetic` YAML：`values: [..]`（不分大小寫，忽略 `-`、`_`、空白）、`ranges: [{prefix, from, to}]`（數字部分含端點）、`patterns: [regex]`（對正規化值 fullmatch）。落在其中的值不算形狀命中，報告逐類列被它放行的數量。不傳時全部照報。 |
| 歧義 | 真值同時是公開值（別名或別條目的假值）⇒ 列「歧義」節並計出現次數，不算命中。總表列總次數與前 20 個樣本；次數 >0 時報告第一行是警告。 |
| 正規化視圖 | 原文之外另掃：URL 解碼（`+` 視為空白，反覆解到不變、最多 3 次）、HTML 實體解碼、JSON `\u` 解碼、`\xHH` 與八進位跳脫解碼、全形轉半形、移除所有 Unicode 格式控制類（Cf）字元、空白正規化（所有 Unicode 空白→一般空白、連續空白含換行壓成一個、行首 `#`／`//`／`*` 註解前綴在壓行時去掉，只掃跨空白的多字名稱、電話與通用樣式）、千分位逗號去除（只掃數字、形狀與表內 regex）。與原文同行同鍵的重複命中不重報，命中標明視圖。 |
| 文字解碼 | 依序嘗試：BOM 判定的 UTF-32／UTF-16、UTF-8（含 BOM）、無 BOM 的 UTF-16LE 與 UTF-16BE（UTF-8 解不出合理文字或 NUL 佔 ≥5% 時）、cp950（UTF-8 失敗時）。「合理」＝嚴格解碼成功且控制字元、未指派、私用、代理字元 ≤0.5%。每個合理候選都掃一次（非 UTF-8 的視圖名前綴編碼名）；都不合理才當二進位檔。 |
| 二進位檔 | 以位元組掃：≥5 字真名（不分大小寫）、≤4 字真名與衍生形（大小寫精確，前後不接英文字母、可接複數）、對照表數字真值（前後不接數字；字母類另掃全小寫），各 ASCII、UTF-16LE、UTF-16BE 三形。 |
| 壓縮容器 | zip 系（含 xlsx／docx／pptx）與 gzip 依魔術位元組判定並解開，成員以 `容器!/成員` 為路徑照一般檔案流程掃（成員名也當路徑掃）。遞迴深度上限 2；單一成員或解壓輸出上限 50 MB。超限、加密、壞檔列報告「Not scanned」節，屬警告不算命中。 |
| `.git` | 樹內 `.git` 目錄除 `objects/` 外的所有檔案照一般檔案掃（含 `config`、`COMMIT_EDITMSG`、`logs/`、`packed-refs`、`description`）；另以唯讀 `git log --all` 與 `git for-each-ref` 取出每個 commit／tag 的作者、信箱、訊息與 ref 名，以 `.git!/git-metadata` 為路徑掃。git 跑不起來列「Not scanned」。 |
| 通用樣式 | 腳本開頭 `GENERIC_PATTERNS`：非 example 網域電子郵件（表內公開信箱放行）、Windows 家目錄（含 `/c/Users/` 形）、UNC、私有 IPv4、內部主機字尾、網域帳號、台灣市話與手機（含空白分隔與完全無分隔；無分隔形須是獨立 token）。 |
| 豁免 | `verify_exempt.yaml`，每筆必備 `name`、`path`、`context`、`reason`、`approver`，缺欄即退出碼 1；報告列出每筆放行了幾處。`name` 可以是衍生形、表內 regex 樣式原文或 `shape:<類>`。 |

| 8 | — | 報告「Hits before / after exemptions」逐類三欄；「Exemption usage」逐條列放行數、占該鍵比例，放行 ≥20 或「`*` 路徑且無 context」者標 **REVIEW**。豁免名比對不分大小寫與分隔（`First_Last` 可放行 `First Last`），round-3 類別鍵 `<類>:<字>` 也可用裸字放行。 |

## 對規格的延伸（非縮減）

1. `keep` 條目的真名（>4 字）也加入遮罩：被保留的片語內出現真名字樣不算命中（例：保留片語內含產品詞）。
2. 縮寫邊界：`ABCWord` 中 `ABC` 與 `Word` 之間也算邊界。
3. 表中標 `scan: false` 的條目**照掃**（獨立性優先），報告在該鍵旁註記 `[table: scan:false]` 供判讀。
4. `--selftest` 帶 `--maps` 時，另檢查原始碼不含任何對照表真值；帶 `--names` 時也用表內 regex 條目檢查原始碼。
5. `.git` 內除 `objects/` 外全部掃（規格列的四類之外，`description`、`hooks/`、`info/`、`index` 也掃）。
6. 歧義與遮罩計數：原文逐次計，其他視圖／解碼只補原文沒涵蓋的行（避免同一處被每個視圖重複計）。

## 判讀取捨（第二輪自行決定、請主持人裁）

1. 多字名稱的首／尾字 ≤4 字元時，該側套短名邊界（不含複數）。沒有這條，「兩字名的姓是短字」這類人名會以子字串命中 `max_lines` 這種識別字（第二輪 r3 實測一個人名 16 筆全是這種）。
2. 形狀本體的字母位置保留大小寫類別（大寫／小寫分開），前綴仍不分大小寫。沒有這條，序號形會吃掉 CSS 色碼（`#b07d12` 之類，r3 實測近 200 筆）。
3. 無分隔的電話形須是獨立 token（前不接英數、後不接字母），避免 16 位雜湊內的 10 位數被報。
4. 表內 regex 帶 `permutation` 者，擷取值不在對照表 ⇒ 列警告不算命中（置換後的公開值本來就不在表內，無從分辨）。

## 已知限制（明確不做）

- Base64、十六進位編碼（整串轉成 hex 位元組的形）、字串反轉、相似字元替換（西里爾字母等 homoglyph）。
- 程式碼裡的字串相加拼接（`"Zor" + "blaxia"` 這種）。
- 兩層以上變形疊加（例：URL 編碼的零寬字元、HTML 實體裡再放全形）。每個視圖只從原文做一種變換。
- 數字嵌在更長的數字串內（七位數內含的 5 位真值不報）。
- 形狀掃描不涵蓋純數字類（無字母前綴的五位數、六位數群組），否則一般數字會全部被報；純數字類只做逐值比對。
- 也未處理（不在本輪 19＋2 條內）：Markdown 強調斷字（`Zor**blaxia**` 形）、在真名原本沒有分隔處插入分隔的變形（只有剛好命中另一條多字真名時才會抓到）。

## 自測

`--selftest` 使用腳本內建的迷你假表與假樹（暫存目錄，跑完刪除），不讀真表；
涵蓋每條規則的正反例（第一輪 R1–R21、第二輪 N1–N20、第三輪 T1–T12，每項至少一正一反）、唯讀（含 `.git`）、報告路徑防呆、退出碼、報告節次；
`.git` 案例在暫存假樹內用 git 建一個 commit（需要 PATH 上有 git）。
帶 `--names`（與 `--maps`）時加跑原始碼潔淨檢查。

## 報告節次

第一行警告（歧義／未掃／regex 編譯失敗／regex 未對應值，有才出現）→ 總表（Summary、歧義前 20 樣本、Hits per key）
→ 逐名命中（檔案、行號、前後各 30 字元；行號 `path` 表示命中在路徑、`bin` 表示二進位位移）→ 數字命中 → 通用樣式命中
→ 形狀命中 → 形狀樣式表（每類真／公開前綴、本體形狀、命中與放行數）→ 雜湊形略過樣本 → 歧義 → regex 未對應值
→ regex 編譯錯誤 → 未掃 → 遮罩 → 豁免使用。

| 1 | `real_stat` | `--stats` 每行一個值（`#` 註解、可含千分位逗號；空檔＝規則關閉；非數字行＝退出碼 1）。只收整數位 ≥4 位或帶千分位者（其餘計入「dropped」）。內容中出現原樣、去千分位、加千分位三形之一，前後不接數字、也不是小數的一部分（`7777.5` 不算 `7777`）即命中；≥16 位十六進位串內者列雜湊略過。鍵 `real_stat:<去千分位值>`，可用裸值豁免。只掃文字內容（不掃路徑、二進位）。 |
